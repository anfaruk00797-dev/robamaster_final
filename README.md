# RoboMaster — เลือกเป้าที่บันทึกและยิง IR

ชุดใหม่คัดลอกโค้ดและค่า HSV ล่าสุดจาก robomaster_final

## เริ่มใช้งาน

เปิดโฟลเดอร์นี้ด้วย Python environment เดิมที่มี RoboMaster SDK, OpenCV และ NumPy แล้วรัน `python map_scan.py`

โปรแกรมถามรหัสเป้าก่อนเชื่อมต่อหุ่น เช่น `ub,or,pg` หรือระบุโดยตรงด้วย `python map_scan.py --targets ub,or,pg`

- รูปทรง: `u` สี่เหลี่ยมจัตุรัส, `o` วงกลม, `i` สี่เหลี่ยมแนวนอน, `p` สี่เหลี่ยมแนวตั้ง
- สี: `r` แดง, `y` เหลือง, `g` เขียว, `b` น้ำเงิน

แต่ละรหัสหมายถึงชนิดเป้าทุกอันที่พบ ไม่ใช่จำนวนเป้า โปรแกรมแสดงการตรวจจับทุกสี แต่เลือกเล็งและบันทึกเฉพาะรหัสที่กรอก เมื่อจุดกลางเป้าเข้ากรอบสีส้ม กิมบอลหยุด บันทึกตำแหน่ง แล้วส่งคำสั่งยิงอินฟราเรด 1 ครั้ง โดยบันทึกผลยืนยันใน `ir_status` หากคำสั่งไม่ยืนยัน โปรแกรมหยุดโดยไม่ยิงซ้ำอัตโนมัติ

## Alignment และขยับห่างเป้าก่อนยิง

ก่อนเริ่มตรวจจับ โปรแกรมใช้ขั้นตอนจาก `alig.py` กับการเชื่อมต่อหุ่นเดียวกัน: อ่าน ToF สแกนผนัง แล้วปรับ yaw ฐานตามผล alignment เมื่อจบจึงกำหนดทิศเริ่มต้นของแผนที่และเริ่มสแกนกล้อง ถ้าตรวจไม่พบผนังหรือยืนยัน alignment ไม่ได้ จะรายงานผลและทำงานต่อเหมือนพฤติกรรมเดิมใน alig.py ค่าปรับ alignment ยังคงใช้จากไฟล์นั้น

การตรวจจับและ mask ใช้ภาพเต็มจอ รวมส่วนล่าง 25% ที่เคยตัดออก ขั้นตอนเมื่อพบเป้าคือ:

1. พบรูปทรงที่มีสีตรงกับสีที่กรอก เช่น กรอก `py` จะพิจารณารูปทรงสีเหลืองก่อน
2. หยุดกิมบอลและขยับฐานออกจากด้านที่เป้าอยู่ 10 ซม. โดยไม่หมุนฐาน: เป้าอยู่ขวา → สไลด์ซ้าย, อยู่ซ้าย → สไลด์ขวา, อยู่หน้า → ถอย, อยู่หลัง → เดินหน้า (เลือกด้านที่ใกล้มุมเป้าที่สุด)
3. รอฐานขยับเสร็จ ตรวจรูปทรงให้ตรงรหัสจริง แล้วเล็งเข้าในกรอบสีส้ม บันทึกและยิง IR 1 ครั้ง
4. สั่งขยับกลับด้วยระยะตรงข้าม 10 ซม. รอให้เสร็จ แล้วหมุนสแกนต่อจากมุมกิมบอลที่ยิง

ถ้าเป้าหายหรือยืนยันรูปทรงไม่ได้ จะกลับก่อนแล้วสแกนต่อโดยไม่ยิง หากคำสั่ง IR ไม่ยืนยัน จะกลับแล้วหยุดโดยไม่ยิงซ้ำ กด `q` คือหยุดทันที จึงไม่สั่งเคลื่อนกลับอัตโนมัติเมื่อผู้ใช้ขอหยุด ระยะไป–กลับใช้คำสั่งระยะของ SDK; ยังต้องทดสอบความคลาดจากล้อกับพื้นจริง

จุดสีบนแผนที่อ้างอิงภาพก่อนขยับฐาน และเก็บมุมกิมบอลตอนยิงแยกต่างหาก เพื่อไม่เอามุมจากตำแหน่งที่ถอยแล้วมาปนกับจุดเดิม หน้าต่างกล้องกับ mask ยังอัปเดตระหว่างการขยับฐาน

ยังมีหน้าต่างกล้อง, Detection mask, แผนที่, จุดสีและกรอบดำสำหรับเป้าที่บันทึกแล้ว รวมทั้งกติกาเลือกครึ่งภาพตามทิศหมุน กด `q` เพื่อหยุด และ `h` เพื่อโหลด HSV ใหม่

ความเร็วสแกน 90°/วินาที ช่วงชะลอ 24°/วินาที ความเร็วเล็งสูงสุด yaw 40°/วินาที และ pitch 24°/วินาที ปรับค่าที่ต้นไฟล์ map_scan.py ได้

มุม pitch เริ่มต้นก้มลง 8° ระหว่างหมุนสแกนจะก้ม–เงยวนระหว่าง −20° กับ −8° จึงไม่เงยถึงระดับกลาง 0° ความเร็วสูงสุด 12°/วินาทีและชะลอใกล้จุดกลับทิศ เมื่อพบเป้าจะพักลูปเพื่อเล็งตามเป้า หลังบันทึกและยิง IR จะกลับเข้าสู่ลูปสแกนต่อ ปรับช่วงมุมได้ที่ `SCAN_PITCH_LOW_DEG` และ `SCAN_PITCH_HIGH_DEG` ใน `map_scan.py`

ผลการรันเขียนลง `target_map.json` และ `target_map.png` ในโฟลเดอร์นี้ เมื่อสแกนครบจะเปิดกราฟให้ดู แผนที่ยังสมมติพื้นที่ 1×1 เมตร หุ่นอยู่กึ่งกลาง และเป้าอยู่บนขอบแผนที่ จึงเป็นตำแหน่งประมาณจากมุม ไม่ใช่ระยะที่วัดจริง
